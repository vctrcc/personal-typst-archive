# Documents & Templates

Personal source files and templates compiled using [Typst](https://typst.app/).

## Contributing
If you arrived here from a compiled document and found an error, typo, or missing formula. Or just want to improve on it:
1. Navigate to that document's folder under `courses/`.
2. Edit the file directly or fork the repository.
3. Compile the typst code (Use the AI skills if you want)
4. Ask someone from the dirve to update the document.
